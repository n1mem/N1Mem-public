② 为什么 BYOK 是安全的（也给评审者）

  • ✓ 零密钥泄露：所有脚本只读环境变量，缺失即报错；仓库内无任何 key。
  • ✓ 费用自担：调用全部计费到你的 OpenRouter / 百炼账户，N1Mem 看不到用量。
  • ✓ 可审计：冻结产物带 SHA256；verify_public.py 输出完整性校验；CLAIM.template.md 供署名背书。
  • ✓ 最小权限：问答基准只需 Judge key；端到端模式才需 Reader key。

③ 三步跑起来

# 1) 填你自己的 key（仅 OPENROUTER_API_KEY 必填）
cp repro_byok/.env.example repro_byok/.env
# 编辑 .env：OPENROUTER_API_KEY=sk-or-...

# 2) LongMemEval（先构建官方 Gold，约 ~1h）
python repro_byok/longmemeval/build_gold.py --data <官方longmemeval目录> --out repro_byok/longmemeval/inputs/lme_gold.json
python repro_byok/longmemeval/run_judge_byok.py --gold repro_byok/longmemeval/inputs/lme_gold.json --full

# 3) LoCoMo 主口径 95.52%（Checklist-CoT，~30min）
python repro_byok/locomo/freeze_or10_checklist.py --smoke 10
python repro_byok/locomo/freeze_or10_checklist.py --full

# 4) MemoryAgentBench（干跑出脚手架；真跑需克隆官方仓库）
python repro_byok/amb/run_agent_byok.py --dry-run

# 5) LME-V2 零依赖校验
python repro_byok/longmemeval-v2/verify_lmev2.py

# 6) 全量中立校验（无需 API key）
python verify_public.py

④ 验证费用说明

所有复现/校验均在你自己的 API key 下运行，费用由你自行承担，N1Mem 看不到、也不承担这些费用。零依赖校验（verify_public.py / verify_lmev2.py）无需任何 API key。

ⓘ 关于「不依赖最终分数」：本包是复现骨架——脚本与冻结产物已就绪，但最终分数由复现方运行后产生。verify_public.py 只做 SHA256 校验 + 计分 + 断言，不引入任何预置结论。
